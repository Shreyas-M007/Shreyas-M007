### 👨‍💻 About Me

I’m a sophomore **Artificial Intelligence & Machine Learning** student at **B.M.S. College of Engineering (BMSCE)** with an interest in machine learning applications, software development, and interactive web projects.

- 🌾 **Active Project:** [AgriMate](https://github.com/Shreyas-M007/Agrimate) — Agricultural market intelligence platform powered by verified APMC records.

- 🤝 **Civic Project:** [Jan-Sathi](https://github.com/Shreyas-M007/Jan-Sathi) — Public welfare eligibility matching portal.
- 📚 **Freshman Project:** [Library System](https://github.com/Shreyas-M007/library-management-system) — Automated borrower tracker built with Streamlit & OOP.
- ⛰️ **When AFK:** Trail exploring, road biking, and astrophotography / stargazing.
